## 2024-05-19 - Fast-Path Avoidance of T-State Increment
**Learning:** `applyContentionIfNeeded` is called on almost every single memory/port access in the core emulator loop. Although it delegates to `this.tick` and ultimately `this.tStates += count` and `this.totalTStates += count`, avoiding these calls entirely when `count` is 0 avoids the overhead of the function invocation and the useless addition. In V8/JS engines, eliminating a function call inside a heavily exercised method (`this.tick` inside `applyContentionIfNeeded`) results in a measurable speed up because it shrinks the hot code path.
**Action:** When a side-effecting function is called millions of times per second (like `this.tick`), consider adding an early check to skip the call if the effect is a no-op (e.g., adding 0), reducing function call overhead.
